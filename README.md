# fodie-games-site

Site vitrine du studio **Fodié Games**, hébergé sur GitHub Pages.

👉 https://mrgmf.github.io/fodie-games-site/

## Contenu

- `index.html` : accueil (studio + jeux)
- `confidentialite.html` : politique de confidentialité (requise par Google Play et l'App Store)
- `support.html` : page de contact (requise par Google Play et l'App Store)
- `mentions.html` : mentions légales (DSA)

## Mettre en ligne (une fois)

1. Pousser ce dépôt sur `MrgMF/fodie-games-site` (public).
2. Settings → Pages → Source : `Deploy from a branch`, branche `main`, dossier `/ (root)` → Save.
3. Attendre 1 à 2 minutes, le site est en ligne à `https://mrgmf.github.io/fodie-games-site/`.

Pour modifier le contenu : éditer les fichiers et pousser sur `main`.
